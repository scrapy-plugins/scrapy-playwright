.. description starts

A Scrapy_ download handler that performs requests using `Playwright for
Python`_. It can be used to handle pages that require JavaScript (among other
things), while adhering to the regular Scrapy workflow (i.e. without
interfering with request scheduling, item processing, etc).

.. _Playwright for Python: https://github.com/microsoft/playwright-python
.. _Scrapy: https://scrapy.org/
